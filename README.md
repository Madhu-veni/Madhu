# 🌐 Azure Hands-On Activities – June 2025

This repository contains hands-on exercises and practical tasks completed as part of my Azure course.

## 📘 Course Overview

The activities are aligned with core modules in Microsoft Azure training, focusing on real-world application of cloud services.

## 🔧 Hands-On Modules Completed

- 💰 **Budgets**  
  Configured Azure budgets to track cloud spending and set alerts to avoid overspending.

- 🧱 **Resource Groups**  
  Created and managed Azure resource groups to logically group related services for easier administration.

- 🗃️ **Storage Accounts**  
  Set up general-purpose v2 storage accounts to manage blobs, queues, tables, and files under a single resource.

- 📦 **Blob Storage**  
  Uploaded and managed unstructured data like images and documents using Azure Blob Storage.

- 📁 **File Sharing**  
  Created Azure File Shares to enable file-based access to storage over SMB protocol.

- 📊 **Table Storage**  
  Built NoSQL key-value table storage solutions for structured data with fast access.

- 📬 **Queue Storage**  
  Configured queue messaging between application components to enable decoupled communication.

- 📂 **Containers & Container Instances**  
  Created Azure Container Instances to deploy containerized apps quickly without managing underlying infrastructure.

- ⚙️ **Storage Containers**  
  Organized and managed blobs within containers under the Azure Storage account.

- 🌐 **Networking**  
  Set up virtual networks, subnets, and configured network rules for secure and connected deployments.

- 🔁 **Load Balancers**  
  Implemented Azure Load Balancers to distribute incoming traffic and improve app availability.

- 📡 **IoT Hub**  
  Configured Azure IoT Hub to connect, monitor, and manage IoT devices securely.
